# GIP Navigator

GIP Navigator — универсальная рабочая книга Microsoft Excel для календарного плана, сопутствующих работ (СР) и контроля.

## Для ГИПа

Нужен один файл: [`templates/GIP_Navigator_TEMPLATE.xlsm`](templates/GIP_Navigator_TEMPLATE.xlsm).

1. Скопируйте его в папку проекта и переименуйте копию.
2. Откройте копию в Microsoft Excel и разрешите макросы в соответствии с корпоративной политикой.
3. На листе `00_Главная` нажмите **«Импортировать КП»**.
4. Выберите исходный календарный план в формате `.xlsx` или `.xls`, проверьте предпросмотр и подтвердите импорт.

Импорт читает исходный КП без изменения. До записи данных книга создаёт резервную копию рядом с рабочим файлом. При повторном импорте H:I сохраняются по стабильному номеру этапа; если этап с фактом исчез из нового КП, импорт остановится с конфликтом.

## Состав книги

- `01_КП` — от 2 до 75 этапов календарного плана;
- `02_Библиотека_СР` — библиотека из 81 типовой СР;
- `03_СР_проекта` — независимые экземпляры СР. Один код библиотеки можно добавить несколько раз кнопкой «Добавить экземпляр СР»;
- `04_Согласование_плана` — связи между СР: несколько предшественников, FS/SS и лаг;
- `05_График`, `06_Контроль` — рабочие модули проекта.

В `01_КП` колонки A:G остаются договорными и заполняются импортом. В H:I ГИП вводит дату и сумму фактического актирования, а J:K автоматически показывают остаток и процент. Начало внутренней сети СР — минимальная дата начала импортированного КП. Сроки включительны: при FS последующая СР начинается на следующий день после окончания предшественника; при SS — от даты его начала. Лаг считается по календарю последующей СР.

PowerShell, Python и другие внешние инструменты не требуются ГИПу для создания рабочей книги и первоначального импорта КП. Скрипты в `tools/` предназначены только для сопровождения и тестирования шаблона разработчиком.
